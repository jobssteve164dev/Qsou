# 规划蓝图：数据采集层插件化架构
*   **状态**: [进行中]

## 1. 核心目标与验收标准 (Core Objective & Acceptance Criteria)

### a. 核心目标 (Core Objective)
*   将 Scrapy 爬虫体系改造成“可插拔插件”模式。新增爬虫只需把插件包放入 `crawler/plugins/`（或通过 Python entry point 安装），即可被自动发现、列出与启动，无需改动核心代码。

### b. 验收标准 (Acceptance Criteria)
*   [ ] 定义 `SPIDER_LOADER_CLASS` 为自研 `PluginSpiderLoader`，支持发现多个插件源。
*   [ ] 支持两种发现方式：
    *   目录扫描：`crawler/plugins/**/spiders/*.py`
    *   Python entry point：`qsou_crawler.plugins`
*   [ ] `scrapy list` 能显示插件蜘蛛名称。
*   [ ] `crawler/run_crawler.py` 动态列出全部可用蜘蛛并可启动任意一个。
*   [ ] 提供一个可运行的示例插件 `example_news_plugin` 并通过验证。
*   [ ] 提供开发文档 `docs/crawler-plugins.md`，指导如何编写与安装插件。

## 2. 现状分析与复用性尽职调查 (Current State Analysis & Reuse Due Diligence)

### 复用性尽职调查
*   **搜索关键词**: `plugin`, `SpiderLoader`, `SPIDER_LOADER_CLASS`, `plugins`, `entry_points`
*   **搜索范围**: `crawler/qsou_crawler/`, `crawler/run_crawler.py`
*   **发现与结论**:
    *   现有 `settings.py` 使用默认 `SPIDER_MODULES` 与内置 `spiders/`，未有插件发现机制。
    *   运行脚本 `run_crawler.py` 以静态列表方式启动固定蜘蛛，无法动态扩展。
    *   结论：需要新增自定义 SpiderLoader 并改造启动脚本以动态发现。

## 3. 技术方案与架构设计 (Technical Approach & Architecture Design)

*   新增 `qsou_crawler/plugin_loader.py`：实现 `PluginSpiderLoader` 扩展模块搜索路径：
    *   读取 `CRAWLER_PLUGIN_DIRS`（默认 `crawler/plugins`）扫描包并追加 `<pkg>.spiders` 到 `SPIDER_MODULES`。
    *   读取 `CRAWLER_PLUGIN_ENTRYPOINT_GROUP=qsou_crawler.plugins`，通过 `importlib.metadata` 解析 entry points 并追加模块。
*   修改 `settings.py`：
    *   设置 `SPIDER_LOADER_CLASS` 指向自定义加载器。
    *   增加 `CRAWLER_PLUGIN_DIRS`、`CRAWLER_PLUGIN_ENTRYPOINT_GROUP`、`CRAWLER_PLUGIN_AUTO_ENABLE`。
*   改造 `run_crawler.py`：
    *   通过执行 `scrapy list` 动态列出可用蜘蛛；交互式选择并启动。
*   示例插件 `crawler/plugins/example_news_plugin`：
    *   提供 `spiders/example_yicai_spider.py`，产出 `NewsArticleItem`。
*   文档 `docs/crawler-plugins.md`：
    *   开发、目录结构、调试与发布（可选 entry point）说明。

## 5. 风险评估与应对策略 (Risk Assessment & Mitigation Plan)

*   兼容性风险：不同 Python 版本 `importlib.metadata` API 差异。
  *   应对：提供 `importlib_metadata` 回退方案。
*   路径解析风险：在不同工作目录下定位 `crawler/plugins`。
  *   应对：以 `qsou_crawler` 包路径为基准解析绝对路径并 `sys.path.insert`。
*   设置合并风险：插件额外 settings 与核心 settings 的冲突。
  *   应对：首期仅支持蜘蛛发现；后续再引入可控的 settings 合并策略。
