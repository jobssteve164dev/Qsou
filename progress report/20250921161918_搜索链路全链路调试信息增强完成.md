### c. 关键代码片段

**示例: 前端API客户端Trace-ID传递**
```typescript
// web-frontend/src/services/api.ts
apiClient.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('auth_token');
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
    // 生成或传递Trace-ID
    const traceId = config.headers['X-Trace-ID'] || generateTraceId();
    config.headers['X-Trace-ID'] = traceId;
    console.log(`[API] ${config.method?.toUpperCase()} ${config.url}`, { traceId });
    return config;
  }
);
```

**示例: 后端中间件Trace-ID透传**

```python
# api-gateway/app/middleware/request_logging.py
incoming_trace_id = request.headers.get("X-Trace-ID") or request.headers.get("x-trace-id")

response.headers["X-Trace-ID"] = request_id
```

## 5. 自我评估与学习 (Self-Assessment & Learning)

*   **遇到的挑战**: 向量维度不匹配导致Qdrant查询失败，需要同时调整嵌入模型和集合配置；前端期望的数据结构与后端返回不一致，需要做形状适配
*   **学到的教训**: 调试复杂系统时，必须建立端到端的可观测性，通过Trace-ID串联各个组件；向量搜索系统的维度配置必须严格一致，任何不匹配都会导致查询失败；前端API适配层的重要性，可以避免大规模组件修改
