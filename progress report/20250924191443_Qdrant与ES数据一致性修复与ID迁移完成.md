## 2. 核心实现 (Core Implementation)

### a. 方法论/设计思路
采用了"根因分析 -> 数据回填 -> 结构统一 -> ID迁移"的四阶段方法。首先通过数据计数分析发现Qdrant与ES存在1,406条数据差异，然后实现了幂等的数据回填机制，接着统一了ES索引结构（合并旧索引到qsou_documents_v1），最后将Qdrant的随机UUID点ID迁移为确定性ID（基于content_hash或url|title|publish_time的哈希），实现了两个系统间的ID一致性映射。

### c. 关键代码片段 (Key Code Snippets)

**示例: Qdrant确定性ID生成**
```python
# data-processor/vector/vector_store.py
def _store_batch(self, vectors: np.ndarray, documents: List[Dict[str, Any]]) -> List[str]:
    for vector, document in zip(vectors, documents):
        # 使用ES文档ID作为Qdrant点ID，确保一致性
        point_id = document.get('_id')  # 优先使用ES文档ID
        if not point_id:
            # 回退到确定性哈希
            id_string = f"{document.get('url', '')}|{document.get('title', '')}|{document.get('publish_time', '')}"
            if id_string == "||":
                point_id = str(uuid.uuid4())
            else:
                point_id = hashlib.md5(id_string.encode('utf-8')).hexdigest()
```
